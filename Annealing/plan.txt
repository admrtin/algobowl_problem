============================ Annealing idea =====================================

Part 1. (optional). Fill the board with bulbs
- Greedy. Fill the board with bulbs 'L' that lit all cells.
- Deterministic. Find cells with light bulbs that are uniquely determined
- Skip. Proceed to the other stage.

Part 2. Annealing. 
Do one of the following with some probability:
- Lit a cell
- Turn off a bulb
- Move bulb to an adjacent cell
- Move bulb to the next row-vice, column-vice numbered wall 

Define vn = # new violations, vo = # old violations and Δ = vo - vn.  

If 
    Δ >= 0 apply the change
    Δ < 0 apply with probability e^(-Δ / T), where T is the current interation

Part 3. Large Neighborhood Search (LNS). Local search over the window. 

Consider each violation at a cell. Try to fix it using nxn windows.
- Start with n = 3
- For current n, run dfs recursive calls the check all toggles.
- If the number of violations in the square is worse then at the start, abandon 
- Increase by 2 as needed. Keep max of n. Max tree depth as well.
